# 大專院校 3D 校園地圖

可旋轉、縮放的 3D 校園導覽網頁，目前完成九所學校的模型：

- **國立雲林科技大學**：依學校官方空拍正射圖與 2025 校園配置圖建模
- **東海大學**：依 OpenStreetMap 建築輪廓與東海校園地圖建模
- **國立臺灣大學**：依 OpenStreetMap 建築、道路與水域向量資料建模（校總區，含基隆路東側）
- **國立臺灣科技大學**：與臺大共用同一張地圖，切換學校時另一所會變暗
- **國立臺北商業大學、大同大學、臺北醫學大學、國立暨南國際大學、國立屏東科技大學**：依 OpenStreetMap 建築與樓層資料生成，並補上各館簡介

其他學校顯示為「施工中」。

## 首頁：全台大專院校地圖

進站先顯示網站名稱與 logo，接著淡出為臺灣縣市地圖：

- 滑過縣市會浮起上色，點下去放大到該縣市，列出所有大專院校（分技職體系／一般大學）
- 點學校名稱進入 3D 校園；3D 畫面左上角的返回鍵回到該縣市地圖
- 收錄 181 所：教育部 103–113 學年度大專校院名錄的全部學校，加上更早合併或停辦的學校與軍警院校；可切換是否顯示已退場／合併的學校

## 使用

直接開啟 `index.html`，或瀏覽 GitHub Pages 網址。

- 拖曳旋轉、右鍵或 Shift 平移、滾輪縮放
- 點建築或左側目錄查看介紹
- 右上角切換日景／夕照／夜景
